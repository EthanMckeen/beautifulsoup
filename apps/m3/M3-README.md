# Milestone-3
In Milestone 2, SoupReplacer was configured with data inputs and a hard-coded conditional rule. The user could only interact with it by adjusting the input values. In Milestone 3, users have more flexibility: they can write the conditional themselves instead of relying on us, the library authors, to anticipate it. This gives up some of the safety and simplicity of Milestone 2. For example, user code now runs on every tag in the middle of parsing, which required extra bookkeeping to keep closing tags matched to renamed tags. I recommend shipping the transformer API (Milestone 3) as the core of SoupReplacer and keeping the pair form (Milestone 2) as a convenience shortcut built on top of it.
